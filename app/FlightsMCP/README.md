# FlightsMCP

Servidor MCP de vuelos de TripPlanner AI (AgentCore Runtime, protocolo MCP).
Proveedor simulado pero dinamico y reproducible: aeropuertos y aerolineas reales, duracion por distancia, precio por temporada/anticipacion/hora. Tools: `search_flights`, `list_destinations`.

Local: `uv run main.py` -> http://localhost:8000/mcp
